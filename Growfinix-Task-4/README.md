# Growfinix Task 4: Media Production Cost Tracking

## Project Overview

This project focuses on analyzing media production costs and revenue using Python, SQL, and data analysis techniques. It compares two media formats — **DSLR Portraits** and **Cinematic Animation Videos** — to understand their production expenses, revenue generation, profit, and Return on Investment (ROI).

The project demonstrates how data can be cleaned, organized, queried, and analyzed to support business decision-making.

## Objectives

- Analyze production costs for different media formats.
- Calculate total revenue and profit for each format.
- Calculate Return on Investment (ROI).
- Use SQL queries to summarize financial performance.
- Generate structured output files for reporting and further analysis.

## Technologies Used

- **Python** — data processing and automation
- **Pandas** — data cleaning, grouping, and analysis
- **SQLite** — database creation and SQL query execution
- **SQL** — cost, revenue, profit, and ROI analysis
- **CSV** — input dataset and output reports
- **Visual Studio Code** — development environment
- **Git and GitHub** — version control and project hosting

## Dataset Description

The input dataset contains media asset information with the following columns:

| Column | Description |
|---|---|
| `Asset_ID` | Unique identifier for each media asset |
| `Media_Format` | Type of media, such as DSLR Portrait or Cinematic Animation |
| `Production_Cost` | Cost of producing the media asset |
| `Revenue` | Revenue generated by the asset |

The sample dataset is used to demonstrate the analysis workflow. Replace it with the official dataset if one was supplied by Growfinix.

## Methodology

1. **Data Loading:** Import the CSV dataset into Python using Pandas.
2. **Data Cleaning:** Standardize column names, convert financial fields to numeric values, and handle missing or duplicate records.
3. **Database Creation:** Store the cleaned data in an SQLite database.
4. **SQL Analysis:** Execute SQL queries to calculate production costs, revenue, profit, and ROI by media format.
5. **ROI Calculation:** Calculate the return generated relative to the production cost.
6. **Report Generation:** Export the cleaned dataset and analysis results into CSV files.

## Key Performance Metrics

### Profit

Profit is calculated as:

```text
Profit = Revenue - Production Cost
```

### Return on Investment (ROI)

```text
ROI (%) = ((Revenue - Production Cost) / Production Cost) * 100
```

A higher ROI indicates a greater return relative to the production cost.
